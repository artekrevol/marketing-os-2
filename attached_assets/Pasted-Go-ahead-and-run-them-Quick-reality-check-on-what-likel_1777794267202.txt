For query 1, one refinement: filter out status='error' runs from the denominator. A check that errored is neither pass nor fail — including it in the rate dilutes the signal. Use:
sqlSELECT brand_id,
       COUNT(*) FILTER (WHERE status='failed') * 100.0 / 
       NULLIF(COUNT(*) FILTER (WHERE status IN ('failed','approved','rejected')), 0) as hard_fail_pct,
       COUNT(*) FILTER (WHERE status='failed') as failed_count,
       COUNT(*) FILTER (WHERE status='approved') as approved_count,
       COUNT(*) FILTER (WHERE status='rejected') as rejected_count,
       COUNT(*) FILTER (WHERE status='error') as errored_count
FROM qa_runs
WHERE started_at > now() - interval '7 days'
GROUP BY brand_id;
Showing the raw counts alongside the percentage matters because if a brand has 3 runs and 1 failed, "33%" is misleading. Rabia and Maria should see the absolute numbers.
