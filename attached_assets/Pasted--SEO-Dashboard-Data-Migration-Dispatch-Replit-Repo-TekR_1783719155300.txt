# SEO Dashboard Data Migration Dispatch (Replit)

**Repo:** TekRevol Content Platform (Marketing OS) — Replit
**Objective:** Migrate ~58,000 rows of production data from the SEO Dashboard database dump into Marketing OS. Two content phases: core SEO data into existing tables, LLM citation data into new preservation tables.
**Source:** `db_dump.sql` — pg_dump from SEO Dashboard production (Postgres 16.10, dated 2026-07-10). Upload via Replit file system.
**Target:** Marketing OS current database.
**Dispatch type:** Multi-phase sequential migration. Larger than hygiene dispatches; concentrated data work with clear pause points.

### 1.2 Keyword lists (auto-create per target_url)

Group keywords by target_url. Each unique target_url becomes a `keyword_lists` entry. Expected: 54 lists from unique target_urls plus one Uncategorized.

```sql
BEGIN;

INSERT INTO keyword_lists (id, brand_id, name, description, created_at)
SELECT
  gen_random_uuid(),
  '<TEKREVOL_BRAND_ID>'::uuid,
  INITCAP(REPLACE(REPLACE(
    REGEXP_REPLACE(s.target_url, '^https?://[^/]+/', ''),
    '-', ' '), '/', ' - ')),
  s.target_url,
  MIN(s.created_at)
FROM staging_seo_dashboard.keywords s
WHERE s.target_url IS NOT NULL
GROUP BY s.target_url
ON CONFLICT (brand_id, name) DO NOTHING;

INSERT INTO keyword_lists (id, brand_id, name, description, created_at)
VALUES (gen_random_uuid(), '<TEKREVOL_BRAND_ID>'::uuid, 'Uncategorized', 'Keywords with no target URL', now())
ON CONFLICT (brand_id, name) DO NOTHING;

COMMIT;
```

Report count of lists created. Expected: 54 URL-based lists + 1 Uncategorized = 55.

### 1.3 Keywords schema additions + data migration (425 rows)

The dump's `keywords` table has fields the current schema doesn't hold: `target_url`, `priority`, `intent_hint`, `cluster`, `is_core_page`, `track_daily`. Rather than dropping them, add columns.

**Schema additions (scoped transactional DDL only — no blanket drizzle-kit push):**

```sql
BEGIN;

ALTER TABLE keywords
ADD COLUMN IF NOT EXISTS target_url text,
ADD COLUMN IF NOT EXISTS priority text,
ADD COLUMN IF NOT EXISTS intent_hint text,
ADD COLUMN IF NOT EXISTS cluster text,
ADD COLUMN IF NOT EXISTS is_core_page boolean NOT NULL DEFAULT false,
ADD COLUMN IF NOT EXISTS track_daily boolean NOT NULL DEFAULT true,
ADD COLUMN IF NOT EXISTS difficulty numeric(5,2);

ALTER TABLE keywords
ADD CONSTRAINT keywords_priority_check
  CHECK (priority IS NULL OR priority IN ('P0', 'P1', 'P2', 'P3'));

COMMIT;
```

**Update Drizzle schema in `lib/db/src/schema/` to reflect these additions.** Report the diff before committing.

**Data migration:**

```sql
BEGIN;

CREATE TEMP TABLE keyword_id_map (
  old_id integer PRIMARY KEY,
  new_id uuid NOT NULL
);

WITH inserted AS (
  INSERT INTO keywords (
    id, brand_id, keyword_text, list_id, location_id, target_url,
    priority, intent_hint, cluster, is_core_page, track_daily,
    search_volume, difficulty, is_active, created_at, updated_at
  )
  SELECT
    gen_random_uuid(),
    '<TEKREVOL_BRAND_ID>'::uuid,
    s.keyword,
    kl.id,
    lm.new_id,
    s.target_url,
    s.priority,
    s.intent_hint,
    s.cluster,
    s.is_core_page,
    s.track_daily,
    s.search_volume,
    s.difficulty,
    s.is_active,
    s.created_at,
    s.updated_at
  FROM staging_seo_dashboard.keywords s
  LEFT JOIN location_id_map lm ON lm.old_id = s.location_id
  LEFT JOIN keyword_lists kl ON (
    (s.target_url IS NOT NULL AND kl.description = s.target_url AND kl.brand_id = '<TEKREVOL_BRAND_ID>'::uuid)
    OR (s.target_url IS NULL AND kl.name = 'Uncategorized' AND kl.brand_id = '<TEKREVOL_BRAND_ID>'::uuid)
  )
  ON CONFLICT (brand_id, keyword_text, location_id) DO NOTHING
  RETURNING id, keyword_text
)
INSERT INTO keyword_id_map (old_id, new_id)
SELECT s.id, i.id
FROM staging_seo_dashboard.keywords s
JOIN inserted i ON i.keyword_text = s.keyword;

COMMIT;
```

Verify count. Expected: 425 keywords, mapped across 55 keyword_lists.

If existing Marketing OS keywords conflict with dump entries (per Phase 0.3 policy), report the conflict count and skipped rows.

### 1.6 Crawl schedules (1 row)

Only 1 row; migrate to preserve continuity. Adapt from dump's frequency-based schedule to Marketing OS cron-based schedule:

```sql
BEGIN;

INSERT INTO crawl_schedules (
  id, brand_id, list_id, cron_expression, is_active,
  last_run_at, next_run_at, created_at, updated_at
)
SELECT
  gen_random_uuid(),
  '<TEKREVOL_BRAND_ID>'::uuid,
  NULL,
  CASE s.frequency
    WHEN 'daily' THEN '0 2 * * *'
    WHEN 'weekly' THEN '0 2 * * 0'
    ELSE '0 2 * * *'
  END,
  s.is_active,
  s.last_run_at,
  s.next_run_at,
  s.created_at,
  s.updated_at
FROM staging_seo_dashboard.crawl_schedules s;

COMMIT;
```

**Important — schedule activation warning:** The dump's schedule is likely `is_active = true`. Before Phase 1.6 activates, set `is_active = false` and let the dispatcher decide activation policy after import:

```sql
UPDATE crawl_schedules
SET is_active = false
WHERE brand_id = '<TEKREVOL_BRAND_ID>'::uuid
  AND id IN (SELECT id FROM crawl_schedules
             WHERE brand_id = '<TEKREVOL_BRAND_ID>'::uuid
             ORDER BY created_at DESC LIMIT 1);
```

## Phase 2 — LLM citation preservation (new tables)

Create new brand-scoped tables mirroring the dump schemas. No UI is built for these in this dispatch — data preserved for a future AI Research module.

### 2.1 Schema — 6 new tables

Scoped transactional DDL. All brand-scoped. All added to `BRAND_SCOPED_TABLES` allow-list.

```sql
BEGIN;

CREATE TABLE llm_citation_runs (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  brand_id uuid NOT NULL REFERENCES brands(id) ON DELETE restrict,
  run_type text NOT NULL,
  status text NOT NULL,
  started_at timestamptz NOT NULL,
  completed_at timestamptz,
  metadata jsonb NOT NULL DEFAULT '{}'::jsonb,
  created_at timestamptz NOT NULL DEFAULT now()

CREATE INDEX llm_citation_runs_brand_idx ON llm_citation_runs(brand_id);

CREATE TABLE llm_citation_snapshots (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  brand_id uuid NOT NULL REFERENCES brands(id) ON DELETE restrict,
  run_id uuid REFERENCES llm_citation_runs(id) ON DELETE set null,
  entity_type text NOT NULL,
  entity_domain text NOT NULL,
  entity_name text,
  platform text NOT NULL,
  mentions_count integer NOT NULL DEFAULT 0,
  ai_search_volume integer NOT NULL DEFAULT 0,
  impressions integer NOT NULL DEFAULT 0,
  pages_count integer NOT NULL DEFAULT 0,
  mentions_change integer NOT NULL DEFAULT 0,
  ai_search_volume_change integer NOT NULL DEFAULT 0,
  captured_at timestamptz NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX llm_citation_snapshots_brand_platform_idx ON llm_citation_snapshots(brand_id, platform);
CREATE INDEX llm_citation_snapshots_captured_at_idx ON llm_citation_snapshots(captured_at);

CREATE TABLE llm_citation_items (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  brand_id uuid NOT NULL REFERENCES brands(id) ON DELETE restrict,
  snapshot_id uuid NOT NULL REFERENCES llm_citation_snapshots(id) ON DELETE cascade,
  question text,
  answer_excerpt text,
  cited_url text,
  cited_domain text,
  cited_page_title text,
  source_name text,
  snippet text,
  reference_position integer,
  ai_search_volume integer DEFAULT 0,
  impressions integer DEFAULT 0,
  platform text NOT NULL,
  location_code integer,
  language_code text,
  citation_status text DEFAULT 'new',
  notes text,
  intent text,
  captured_at timestamptz NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX llm_citation_items_brand_idx ON llm_citation_items(brand_id);
CREATE INDEX llm_citation_items_snapshot_idx ON llm_citation_items(snapshot_id);
CREATE INDEX llm_citation_items_cited_domain_idx ON llm_citation_items(cited_domain);

CREATE TABLE llm_citation_top_pages (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  brand_id uuid NOT NULL REFERENCES brands(id) ON DELETE restrict,
  snapshot_id uuid NOT NULL REFERENCES llm_citation_snapshots(id) ON DELETE cascade,
  page_url text NOT NULL,
  page_title text,
  citation_count integer NOT NULL DEFAULT 0,
  platform text NOT NULL,
  captured_at timestamptz NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX llm_citation_top_pages_brand_idx ON llm_citation_top_pages(brand_id);

CREATE TABLE llm_competitors (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  brand_id uuid NOT NULL REFERENCES brands(id) ON DELETE restrict,
  competitor_domain text NOT NULL,
  competitor_name text,
  is_active boolean NOT NULL DEFAULT true,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (brand_id, competitor_domain)
);

CREATE TABLE ai_overview_citations (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  brand_id uuid NOT NULL REFERENCES brands(id) ON DELETE restrict,
  snapshot_id uuid REFERENCES llm_citation_snapshots(id) ON DELETE set null,

  source_name text,

  topic_category text,

CREATE INDEX ai_overview_citations_brand_idx ON ai_overview_citations(brand_id);
```
